# ADR-0003: Local infrastructure with Docker Compose

- **Status:** Proposed
- **Date:** 2026-10-17

## Context
Phase 1 needs PostgreSQL, Qdrant, object storage, and Redis locally, without cloud
access, on a laptop that already runs another project on ports 5432 and 6333.

## Decision
`infra/local/docker-compose.yml` (Compose project name `lekha`) with exact image tags:

| Service | Image | Notes |
|---|---|---|
| PostgreSQL | `postgres:16.15-alpine` | Latest 16.x patch; SCRAM password auth |
| Redis | `redis:8.2.10-alpine` | 8.x line (AGPLv3 option); `noeviction` so queued jobs are never dropped; AOF persistence |
| Qdrant | `qdrant/qdrant:v1.19.1` | API key required; telemetry disabled. v1.19.2 was under two weeks old, so not adopted yet |
| Object storage | `chrislusf/seaweedfs:4.48` | See ADR-0005 |

All ports bind to `127.0.0.1` on non-default numbers (15432, 16379, 16333, 18333).
They sit **below 49152** on purpose: Windows reserves random blocks of the dynamic range
(49152–65535) for Hyper-V/WSL after a restart. On 2026-10-19 it reserved 55376–55475,
which swallowed the original Postgres port 55432, so all ports were moved out of that range. Every
service requires credentials generated by `./dev.ps1 setup`. Containers run with
`no-new-privileges`, memory limits, healthchecks, and rotated logs.

## Alternatives considered
- **Native Windows installs**: hard to reproduce, versions drift.
- **Default ports**: clashed with an existing project on this machine.
- **Floating tags (`postgres:16`)**: silent upgrades; rejected.
- **Redis 7.4**: RSAL/SSPL licence (not OSI open source).
- **Valkey**: BSD-licensed and compatible, but the approved stack names Redis.

## Why it fits Lekha
Same services as the production design, reproducible, no cloud cost, nothing exposed on
the local network.

## Trade-offs
About 2.3 GB of container memory limits; Docker Desktop is required. Exact tags must be
bumped by hand to receive security patches.

## Security and operational implications
Credentials on every service, even locally, build the right habits and let tests prove
fail-closed behaviour. This is a local topology only, not a production one.

## Cost
Free.

## Revisit when
Moving to a shared development environment or AWS, or when a pinned image has a security
advisory.
